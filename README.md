# 🤖 Tito — Rule-Based AI Study Buddy

A beginner-friendly Python chatbot that answers basic programming and Object-Oriented Programming (OOP) questions using predefined responses.

## ✨ Features
- Personalized greetings based on the time of day
- Answers basic programming questions
- Explains OOP concepts such as inheritance, polymorphism, abstraction, and encapsulation
- Provides motivational messages
- Simple interactive chat with an exit command

## 🛠️ Tech Stack
- Python
- `datetime` module
- Dictionaries, functions, loops, and conditional statements

## 🚀 How to Run

1. Install Python 3.
2. Clone this repository or download `chatbot.py`.
3. Open a terminal in the project folder.
4. Run:

```bash
python chatbot.py
```
